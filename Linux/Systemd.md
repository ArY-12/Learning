# Systemd #

### Working With Units: ###

-   Units in Systemd are resources that it's able to manage.
-   These include services, timers, mounts, automounts, etc.

### Services ### 

List services available in the environment:
```
sudo systemctl list-units --type=service
```

Start a stopped service:
```
sudo systemctl start service
```

Stop a running service:
```
sudo systemctl stop service
```

Restart a service:
```
sudo systemctl restart service
```

### Journalctl ###

It is a command-line utility used to query and view logs generated by the systemd-journald service on Linux systems.
